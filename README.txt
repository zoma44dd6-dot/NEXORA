الموسوعة الطبية الشاملة — نسخة الموقع

الملفات:
- index.html: صفحة الموقع الرئيسية
- style.css: التصميم المتجاوب
- script.js: البحث التجريبي وتبديل اللغة ونموذج الاستفسار

طريقة الاستخدام:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.
3) ارفع الملفات إلى استضافة مواقع ثابتة بعد مراجعتها.

مهم:
هذه نسخة واجهة موقع أولية وليست موسوعة مكتملة لكل الأمراض. محتوى الأمراض والمستشفيات الموجود أمثلة تجريبية، ويجب مراجعته طبيًا والتحقق من بيانات المستشفيات قبل النشر.

واتساب:
نموذج الاستفسار موجود في الواجهة، لكن الإرسال الفعلي غير مفعّل. لإرسال الرسائل إلى واتساب مع عدم إظهار رقمك للزوار، يلزم خادم خلفي آمن يتصل بواجهة WhatsApp Business Platform. لا تضع الرقم أو مفاتيح API داخل HTML أو JavaScript أو أي ملف عام.

قبل الإطلاق:
- إضافة صفحات ومحتوى طبي موثوق مع مصادر وتاريخ مراجعة.
- إضافة مستشفيات حقيقية بعد التحقق من مواقعها الرسمية.
- إعداد سياسة الخصوصية وشروط الاستخدام والتنبيه الطبي.
- ربط النموذج بخادم آمن واختبار إرسال واتساب.

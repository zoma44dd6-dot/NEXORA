موقع نبض الطبي — نسخة بسيطة بدون تسجيل دخول وبدون قاعدة بيانات أو خدمات مدفوعة

محتويات المشروع:
- index.html: الصفحة الرئيسية والمقالات
- style.css: التصميم المتجاوب
- script.js: البحث والتصنيفات وفتح المقالات ونموذج اقتراح البريد
- privacy.html: سياسة خصوصية أولية
- disclaimer.html: إخلاء المسؤولية الطبية

للنشر المجاني عبر GitHub Pages:
1) ارفع محتويات هذا المجلد إلى المستودع في GitHub (ارفع الملفات والمجلدات، لا ترفع ملف ZIP فقط).
2) افتح المستودع ثم Settings.
3) افتح Pages من القائمة.
4) في Build and deployment اختر Deploy from a branch.
5) اختر Branch: main والمجلد /(root)، ثم Save.
6) انتظر حتى يظهر رابط الموقع في صفحة Pages.

ملاحظات:
- هذه نسخة ثابتة؛ لا يوجد تسجيل دخول أو لوحة تحكم أو قاعدة بيانات.
- المقالات مضافة داخل ملف index.html ويمكن تعديلها من GitHub لكن تعديل المقالات الجديدة يدويًا يحتاج تعديل الملفات.
- نموذج التواصل يفتح تطبيق البريد بعنوان hello@nabd.example وهو عنوان تجريبي يجب تغييره إلى بريدك الحقيقي داخل script.js.
- المحتوى الصحي تثقيفي عام وليس بديلاً عن الطبيب.
- لم يتم إجراء اختبار بناء لأن المشروع لا يحتاج عملية بناء؛ اختبر الصفحات والروابط قبل الاعتماد عليه تجاريًا.

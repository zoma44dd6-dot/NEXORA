# نبض — موقع تثقيف صحي عربي

موقع ثابت (HTML/CSS/JavaScript) بلا تسجيل دخول للزوار، ولا قاعدة بيانات، ولا اشتراك مدفوع إلزامي. يمكن نشره مجانًا على GitHub Pages.

## الملفات
- `index.html`: الرئيسية.
- `articles.html`: مكتبة المقالات مع بحث وتصنيفات وترتيب.
- `articles/`: صفحات HTML مستقلة لكل مقال لتحسين قابلية الفهرسة وظهور عنوان ووصف ومحتوى المقال مباشرة في HTML.
- `about.html`, `contact.html`, `privacy.html`, `disclaimer.html`: صفحات أساسية.
- `assets/articles.js`: بيانات المقالات. لإضافة مقال جديد، انسخ عنصرًا وعدّل `id`, `title`, `category`, `date`, `minutes`, `summary`, `image`, `keywords`, `sections`, `note`.
- `assets/app.js`: البحث والفلاتر وعرض المقالات وبيانات SEO المنظمة.
- `assets/style.css`: التصميم المتجاوب.
- `assets/*.svg`: صور توضيحية محلية.

## نشر مجاني على GitHub Pages من الهاتف
1. فك ضغط ZIP على الهاتف.
2. افتح مستودع GitHub الذي تريد استخدامه.
3. ارفع **محتويات المجلد** مع الحفاظ على مجلد `assets` (لا ترفع ZIP وحده).
4. في المستودع افتح `Settings` ثم `Pages`.
5. ضمن `Build and deployment` اختر `Deploy from a branch`.
6. اختر الفرع `main` والمجلد `/(root)` ثم `Save`.
7. انتظر ظهور رابط الموقع في صفحة Pages.

إذا كان رفع المجلدات من الهاتف صعبًا، يمكن استخدام GitHub في متصفح الكمبيوتر أو أداة رفع ملفات تدعم المجلدات؛ لا تحذف مجلد `assets` لأنه يحتوي على CSS وJavaScript والصور.

## مهم قبل النشر
- رسائل التواصل تفتح واتساب إلى الرقم المحدد مسبقًا برسالة جاهزة؛ يجب على الزائر الضغط على إرسال داخل واتساب. لا يوجد إرسال تلقائي أو تخزين للرسائل داخل الموقع.
- هذه النسخة ثابتة: لا توجد لوحة تحكم أو نظام نشر مقالات من داخل الموقع؛ إضافة المقالات تتم بتعديل `assets/articles.js` ورفع التغيير إلى GitHub.
- الصور رسومات SVG محلية لتجنب الاعتماد على صور خارجية.
- Google Fonts اختياري؛ إذا لم يتوفر الاتصال فسيستخدم المتصفح خطوطًا بديلة.
- المقالات أمثلة تثقيفية عامة وليست استشارة طبية. يجب مراجعتها من مختص مؤهل قبل اعتمادها طبيًا أو نشرها على نطاق واسع.
- أُنشئت صفحات HTML مستقلة للمقالات مع عنوان ووصف وبيانات Article المنظمة داخل HTML. قبل النشر، يجب استبدال `YOUR-USERNAME` و`YOUR-REPOSITORY` في `sitemap.xml` ووسوم canonical داخل صفحات المقالات ببيانات مستودعك.
- أُضيفت مقالات تثقيفية جديدة، لكن المحتوى لم يُراجع من طبيب أو مختص حتى الآن، ولم يتم اختبار الموقع على كل الأجهزة والمتصفحات. يلزم اختبار الروابط والنشر ومراجعة المحتوى طبيًا قبل تقديمه بوصفه مرجعًا طبيًا.
